Who is This Talk For?

  • 🧑‍💻 Engineers building real autonomy
  • 🧓 Evaluating agent frameworks for production
  • 🧑‍🎓 Cutting edge of applied AI
Explain student vs proff talk is hard. 1. outgrown chatbots and want to build something with real autonomy; add agents to their toolkit; 2. Tech leads or senior folks; 3. STUDENDTS CUTTING EDGE APP AI

Talk will cover

  1. Foundations, first principles, anotamy of an agent
  2. Systematic and programmatic approach to the agent's system prompt
  3. LLM from text generator into an agent that can act on the external world
  4. Introduce collegues to a sharp agent as it hits the wall (clean, cheap and fast)
  5. Unpredictable toy into a reliable, engineering-grade system (graph, state, memory)
  6. multi agent collaboratoin & complex team workflows
  7. Making sure not at mercy of any single provider
  8. Out of isolated islands - MCP, A2A, A2UI, AP2
  9. Monolithic prompts to modular, declarative skills changes how you manage agents
  10. "Spec-first" discipline, machine-readable contract before any code is executed
  11. Solving fundamental flaw in stateless LLMs (Memory / IR)
  12. God-mode of agent capabilities, and keeping it from blowing up in your face
  13. Expand the agent's sensory inputs to visual and auditory world
  14. As agents grow in power and autonomy, we must now turn to guardrails (safety & reliability)
  15. How do we mathematically prove this thing is actually doing its job?
  16. Agent as a Service (daemon loop, the watchdog, the heartbeat, the restart policy)
